# Distance Calculator

## Description
This is a simple Python program that calculates the distance between two points on a 2D plane using the Euclidean distance formula. It utilizes the built-in math library for precision.

## How to Run the Program
1. Ensure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Run the file by typing: `python distance_calculator.py`

## Input Needed
The program will ask you to input four numbers:
* `x1` and `y1` (coordinates for the first point)
* `x2` and `y2` (coordinates for the second point)

## Sample Output
Enter x1: 2
Enter y1: 3
Enter x2: 7
Enter y2: 8

The distance between the two points is: 7.07
